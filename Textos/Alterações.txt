
A Opção 1 é a mais adequada para o seu projeto atual. Na prática, você vai usar o navegador como banco de dados local.

O que você deve fazer
1. No cadclientesPF.html

Ao clicar em Salvar Cadastro, os dados devem ser gravados em:

localStorage.setItem(
    'PDV_CLIENTES_PF',
    JSON.stringify(listaClientes)
);

Pelo que vimos anteriormente, isso já está praticamente implementado.

2. No tabClientePF.html

Ao abrir a página:

document.addEventListener(
    'DOMContentLoaded',
    carregarDadosPF
);

A função:

carregarDadosPF()

deve ler:

PDV_CLIENTES_PF

do Local Storage.

Isto também já está implementado no tabCliente_integrado.js.

Uma melhoria que recomendo

No cadclientesPF.html, após salvar com sucesso, redirecione automaticamente para a tabela:

alert('Cliente salvo com sucesso!');

window.location.href =
    'tabClientePF.html';

Assim o fluxo fica:

Cadastro
↓
Salvar
↓
Tabela

que é o comportamento esperado em um sistema PDV.
