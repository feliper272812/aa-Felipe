function escaparHTML(str) {
  if (str == null) return "";
  return String(str)
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;");
}

Essa função serve para proteger o seu código contra ataques de injeção de script (XSS) e evitar quebras de layout ao exibir textos digitados por usuários no navegador. [1] 
Ela transforma caracteres especiais do HTML em "entidades HTML", que são códigos seguros que o navegador apenas desenha na tela, em vez de executar. [2, 3] 
## O que cada linha faz:

* if (str == null) return "";
* Evita erros no código. Se o valor enviado for nulo (null) ou indefinido (undefined), a função retorna um texto vazio.

* .replace(/&/g, "&amp;")
* Substitui o símbolo & (e comercial) por &amp;. É a primeira substituição necessária para não quebrar as regras do próprio HTML.

* .replace(/</g, "&lt;")
* Substitui o sinal de menor < por &lt; (less than). Isso impede a abertura de tags como <blockquote> ou <script>.

* .replace(/>/g, "&gt;")
* Substitui o sinal de maior > por &gt; (greater than). Isso impede o fechamento de tags HTML.

* .replace(/"/g, "&quot;")
* Substitui as aspas duplas " por &quot;. Isso evita que um usuário feche prematuramente um atributo HTML (como value="..." ou href="...") e insira comandos maliciosos. [4] 

## Exemplo prático de uso:
Se um usuário mal-intencionado tentar enviar o seguinte texto em um formulário:

<script>alert('hack')</script>

Após passar pela função escaparHTML(), o resultado gerado será exatamente este:

&lt;script&gt;alert('hack')&lt;/script&gt;

Resultado no navegador: O usuário comum verá o texto <script>alert('hack')</script> escrito na tela de forma inofensiva, e o código do hacker não será executado.
